# CIS.PR — фронтенд

PWA, которая ведёт русскоязычных студентов СНГ через итальянскую бюрократию при
поступлении в Университет Пармы: поступление → виза D → переезд → ВНЖ → жизнь в
Парме. Бэкенд: [cis-backend](https://github.com/aicezhe/cis-backend).

Прод: `cispr.app` (API — `api.cispr.app`). Мобильный-первый: каждая страница —
`max-w-md mx-auto`. Весь текст интерфейса и почти все комментарии — по-русски.

## Жёсткие правила

- **Не выдумывать данные.** Цифры, адреса, сроки, цены — только из реальных сидов
  или из ресёрча с источником. Меняющееся помечать `[TTL]`/`[УТОЧНИТЬ]`.
- **Перед пушем обязательно `npm run build`** (= `tsc -b && vite build` — строже,
  чем `tsc --noEmit`, ловит то, что `--noEmit` пропускает).
- Секреты только в env, никогда в коммит. Репозиторий публичный.
- Коммиты под `aicezhe`, пуш напрямую в `main` (без веток и PR).

## Стек и деплой

React 18 · TypeScript · Vite 5 · Tailwind 3 · react-router v6 · lucide-react ·
Leaflet + MapLibre GL (карта).

Хостинг — **Render** (static site, автодеплой из `main`), перед ним **Cloudflare с
edge-кэшем ~5 минут**: после деплоя изменения видны не сразу, нужен hard-refresh.
Не гоняйся за «пропавшей» правкой — сначала проверь кэш.

Единственная переменная: `VITE_API_URL` (Vite зашивает её в бандл при сборке).

## Три вкладки

Нижний `TabBar` (`active: 'laura' | 'path' | 'loci'`) — проп передаётся **вручную
каждой страницей**, автоопределения по `useLocation` нет. Страницы резервируют
место под него через `pb-28`.

- **PATH** (`/path`) — ядро: 4 этапа (Университет / Виза / Переезд / В Парме).
- **LAURA** (`/laura`) — AI-ассистент (RAG).
- **LOCI** (`/map`) — карта Пармы. Обрати внимание: id вкладки `loci`, а роут `/map`.

## Данные и состояние

Ни менеджера состояния, ни контекста. Повторяющаяся идиома — модульный `let _cache`
плюс `Set` слушателей (`useCurrency`, `useExpenses` и каждый хук сида).

**Сиды** — статические JSON в `public/data/`, грузятся через `fetch('/data/*.json')`
(не импортируются, чтобы не попадать в бандл). Каждый хук в `src/hooks/` владеет
одним сидом и кэширует его сам.

**Страна** (`ru|ua|by|kz`) читается из `localStorage` **в теле рендера**, не в
эффекте — поэтому смена страны применяется только при перемонтировании. Три разных
механизма сосуществуют: подстановка кода в имя файла (`visa_{country}_seed.json`),
ключ внутри одного файла (`costs_seed.json` → `seed.countries[country]`), и
`routes_by_country`.

**Покрытие по странам неровное:** D-виза есть только для `ru` (`D_VISA_COUNTRIES`),
переезд — тоже только `relocation_ru_seed.json`. Для `by`/`kz` эти разделы вернут
`null`, а `useRelocation` будет впустую фетчить несуществующий файл.

**localStorage** — все ключи с префиксом `cispr_`. Там профиль, прогресс, галочки
(JSON-массивы id), адрес, история Лауры, валюта.

**Прогресс — самое хрупкое место.** `PathPage` пересобирает у себя те же id
галочек, которые формируют четыре других страницы (`foundationChecklistIds`,
`programChecklistIds`, `visaChecklistIds`, `relocationChecklistIds`). Контракт
продублирован и ничем не покрыт: поменяешь формат id на `VisaStepsPage` — процент
на `PathPage` молча поедет.

## Визуальный язык

Единый по всем разделам. Канонический образец — `ParmaLifeOverviewPage.tsx`.

Палитра (`tailwind.config.js`): `cream #F4F1E9`, `soft-cream #FEFBF3`,
`navy #1C2A48`, `gold #B89968`. Шрифты: Playfair Display (`font-serif`) + Inter
(`font-sans`). На практике **почти всё — `font-serif`**; `font-sans` только на полях
свободного ввода.

**Шапка раздела — без коробки-плашки:** текст прямо на странице, курсивный золотой
подзаголовок, тонкая золотая линия ровно 72×1px:

```jsx
<div className="mt-4 px-6 text-center">
  <h1 className="font-serif text-navy text-3xl font-bold">В Парме</h1>
  <p className="font-serif text-gold text-base mt-1 italic">Жизнь после переезда</p>
  <span className="block bg-gold/60 mx-auto mt-3" style={{ width: 72, height: 1 }} />
</div>
```

**Сворачиваемые «Шаги»** с галочками — вместо разрозненных блоков. Галочки
самодельные, 24px: отмеченная — `w-6 h-6 rounded-full bg-gold … text-cream` с `✓`,
неотмеченная — `w-6 h-6 rounded-full border-2 border-navy/30`. Отмеченный текст
получает `text-navy/50 line-through`. Блок можно открыть по ссылке извне:
`navigate(to, { state: { openSteps: true } })`.

**Сетка плиток «Подробнее о:»** — всегда `grid grid-cols-2 gap-x-5 gap-y-4`, и при
нечётном числе последняя плитка растягивается на две колонки:

```jsx
<GridButton key={b.to} {...b} wide={gridButtons.length % 2 === 1 && i === gridButtons.length - 1} />
```

Общие компоненты: `RouteCard` (маршруты переезда), `GridButton` (плитки),
`SectionIcon`, `Price`, `Avatar`.

Стилизация — Tailwind **через конкатенацию строк** (`'base ' + (cond ? 'a' : 'b')`),
без `clsx`/`cn`. Все анимации отключаются под `prefers-reduced-motion`.

## Конвенции

- **Страницы — default-экспорт, компоненты — именованный.** Исключения: `TabBar` и
  `SkyIntro` (тоже default).
- Именование: страницы `*Page.tsx`, хуки `use*.ts`, сиды `*_seed.json`, ключи
  localStorage `cispr_*`.
- Пользовательские поля данных с суффиксом `_ru` (`name_ru`, `note_ru`).
- Комментарии по-русски, объясняют **почему**, а не что («юзер просил его не
  менять», «известный баг рендеринга»). Сохраняй этот регистр.
- Каждый асинхронный эффект использует защиту `let cancelled = false`.

## Карта (LOCI)

`MapPage.tsx` использует **обе библиотеки слоями**: react-leaflet владеет картой,
маркерами и попапами, а MapLibre GL даёт только базовую подложку (через плагин
`maplibre-gl-leaflet`, стиль в `lib/lociMapStyle.ts`). Маркеры — `L.divIcon` с
инлайновым HTML, потому что штатные пины Leaflet ломаются под сборщиками.

Deep-link из шага: `navigate('/map', { state: { focus: '<place_id>' } })`.
Страница читает `focus` из `useLocation()`, летит к точке и открывает попап.

Роут `/map` — единственный ленивый (`lazy()` + `Suspense`): MapLibre весит ~500 KB
gzip и нужен только здесь.

## API-клиент

`src/lib/api.ts`. Access-токен держится в **модульной переменной, не в
localStorage** (защита от XSS), поэтому после перезагрузки страницы сессию
восстанавливает `AuthGate` через refresh-cookie.

Ретрай на 401 живёт в приватной `request()`: срабатывает **и на 403** (FastAPI
отдаёт 403, когда заголовка нет вовсе), только при `opts.auth === true` (чтобы 401
от логина читался как «неверный пароль», а не «сессия истекла»), и ровно один раз.

**Важно:** `streamLaura` и весь `chats.ts` ходят мимо `request()` и **ретрая на 401
не имеют**. Сообщение Лауре сразу после перезагрузки страницы упадёт, вместо того
чтобы тихо восстановиться.

## Известные проблемы

- `SectionPage.tsx` дублирует `lib/sectionsData.ts` вторым, разошедшимся хардкодом
  — и цифры не совпадают (€800 против ~€170 за легализацию). Сама страница теперь
  фактически редирект-заглушка: её 533 строки контента рендерятся, только если
  `cispr_program` не задан.
- Две реализации `formatPrice`: `utils/formatPrice.ts` (мультивалютная, используется)
  и `lib/format.ts` (только EUR, **ноль импортёров**) — при том, что именно вторая
  объявляет себя «единой точкой форматирования».
- Комментарии в `lib/api.ts` и `lib/expenses.ts` ссылаются на `AuthProvider`,
  которого не существует; реальный компонент — `components/AuthGate.tsx`.
- Курсы валют захардкожены в `config/currencies.ts` (RUB 95, UAH 45, BYN 3.5,
  KZT 540) с пометкой `TODO v2` — разъезжаются с реальностью без всякого сигнала.
- Нет роута `*` (404).
- `PathPage.tsx` в качестве ника по умолчанию подставляет `'Aicezhe'`.
